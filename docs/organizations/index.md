# 🏢 組織・勢力 アーカイブ

『ゼンレスゾーンゼロ』の世界を構成する主要な公的機関、企業、プロキシ陣営、および裏社会組織の設定や関係性を整理するアーカイブです。

---

## 🏛️ 公的・統治機関

* **新エルド統治局 / 市議会** - 新エルドの行政・統治全般を管轄する最高機関。
* **新エルド治安局 (Public Security)** - 都市の治安維持・犯罪捜査を担当する警察機構。
* **Hollow Special Operations (伴空局 / 対策班)** - ホロウ内部での専門捜査および災害対策を行う公的組織。

## ⚔️ 民間陣営・プロキシ

* **邪兎屋 (Gentle House)** - 万屋として様々な依頼を請け負う小規模陣営。
* **Random Play** - 六分街に佇むビデオ屋を表の顔とするプロキシ拠点。
