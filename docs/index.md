## 💡 考察コンテナ記法について

本Wikiの記事内では、以下のように情報の信頼度や性質を視覚的に区別しています。

::: info 作中事実・公式情報
ゲーム本編のイベント、公式設定資料集、作中文書等から直接確認できる確定情報です。
:::

::: tip 考察・仮説
作中の描写やフレーバーテキストをもとに導き出された推測・考察・仮説です。
:::

::: warning 反証・注意点
提出された仮説に対する反証データや、解釈上の矛盾・注意点です。
:::

::: danger 未解決点・謎
現段階の作中情報では解明されていない謎や今後の確認が必要な課題です。
:::
