# 🧠 考察データベース

作中の描写、フレーバーテキスト、伏線から展開された各種考察・仮説を格納するデータベースです。

::: info 考察作成の原則
本データベースに掲載される考察は、以下の構成を守って記述されます。
1. **前提となる作中事実**（確定データ）
2. **提出される仮説**（理論・推測）
3. **支持する根拠**（証拠）
4. **反証・問題点・競合説**（疑問点・矛盾）
5. **現時点での評価・未解決点**
:::
