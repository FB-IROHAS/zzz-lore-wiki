# ✏️ Wiki 記事エディタ・編集ページ

本ページでは、Wikiの既存ページの編集、下書き作成、オートセーブ、手動保存および編集履歴の切り替え・復元操作を行えます。

::: info 編集機能について
* **オートセーブ (自動保存)**: テキスト編集時にブラウザの `localStorage` へ自動的に下書きが保護されます。
* **手動保存 ＆ 上書き**: 「手動保存・上書き」ボタンを押すと、現在の状態が編集履歴 (Revision) として管理され、いつでも復元可能です。
* **.md ファイル保存**: 「📥 .md ファイル保存」で編集したMarkdownテキストをローカルへダウンロード保存できます。
:::
