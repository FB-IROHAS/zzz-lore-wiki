# GitHubで編集

このページは管理者がMarkdown記事を整えて、GitHub上のリポジトリへ反映するための編集補助エリアです。一般閲覧者がブラウザから公開記事を直接書き換える機能ではありません。

::: info 管理者向けメモ
* 下書きはブラウザの `localStorage` に保存されます。
* ここで整えたMarkdownは、GitHub上の対応ファイルへ反映して公開します。
* 年代表データは管理しやすいよう、UIとは別のデータ構造で扱います。
:::
